Como preparar a pasta de cada AD

    
    
      
  1. No Figma, abra o frame do AD (story 1080×1920, feed 1080×1080 ou 1080×1350).
    2. 
      
  2. Exporte as camadas: selecione todas as camadas de primeiro nível dentro do frame (clique na primeira, Shift+clique na última) → painel Export → + → PNG 1x → Export N layers.
    3. 
      
  3. Exporte a arte completa: selecione o próprio frame → PNG 1x → salve na mesma pasta com o nome referencia.png.
    4. 
      
  4. Solte a pasta aqui. Para vários ADs de uma vez, coloque cada AD em uma pasta e solte a pasta “mãe”.
    5. 
    

    

      Dicas
      
    
        
  • Grupos que você quer animar separados (ex.: lista de benefícios) podem vir num PNG só: o AnimADS divide em linhas sozinho.
    • 
        
  • Brilhos e desfoques grandes ficam no fundo, que ganha um movimento suave.
    • 
        
  • Os vídeos são salvos numa subpasta AnimADS dentro da pasta de cada AD.
